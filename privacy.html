私隱政策與使用條款

最後更新：2026-10-10 ・ 本文件為一般性說明，並非法律意見。

1. 我們收集哪些資料

  • 帳號資料：電郵地址、暱稱，以及你自願填寫的性別與生日（生日只用作生日問候）。
  • 酒窖內容：你加入的酒款資料、相片、品飲記錄、品飲地點與備註。
  • 裝置資料：登入憑證、同步碼，儲存在你的瀏覽器 localStorage / IndexedDB。
  • 邀請資料：如你使用朋友的邀請連結註冊，我們會記錄邀請關係以發放獎勵。
  • 使用限制資料：為防濫用與計算 AI 辨識配額，我們會短暫使用 IP 位址的雜湊或計數（不長期保存原始 IP）。

2. 我們如何使用

  • 提供登入、跨裝置同步、分享連結同探索地圖功能。
  • AI 酒標辨識：你拍攝的相片會傳送到 Anthropic 的 Claude API 作辨識，只用於即時回傳結果。
  • 發送驗證碼電郵：透過 Google Apps Script / Gmail 發出。
  • 資料存放於 Cloudflare（Workers、KV）。

3. 公開內容

你選擇「發布」到探索，或建立「分享連結」後，相關酒款、相片、品飲筆記、暱稱及品飲地點會公開，任何持連結者或探索頁訪客都可以看到。你可以隨時「收回」發布；登出所有裝置會令舊分享連結失效。請勿在公開備註放入敏感個人資料。

4. 贊助購買建議

  • BottleSense 可能顯示由酒舖提供、標明「贊助」的購買建議。
  • 配對只使用酒款屬性（例如酒名、類別、產區），不包含你的電郵、同步碼、位置或任何身份資料。
  • 我們會累計匿名的酒款需求次數（例如某酒款被加入想買清單多少次）及商戶的曝光與點擊次數，只作統計，不會提供個別用戶資料予商戶。
  • 你可以在「設定」中關閉購買建議與匿名需求統計。

5. 你的權利

  • 匯出：設定 → 匯出 CSV。
  • 刪除：設定 → 帳號 → 永久註銷，會刪除雲端酒窖、帳號、相片及你的探索分享。
  • 如需協助，請聯絡：fiveathree@gmail.com

6. 保存期限

帳號資料保存至你刪除帳號為止。探索分享最多保留 90 天；公開酒櫃連結最多保留一年；驗證碼 10 分鐘後失效。

7. 使用條款

  • BottleSense 為個人酒窖管理工具。AI 辨識與價值評分只供參考，不構成投資、估值或購買建議。
  • 年齡：本服務只供年滿 18 歲（並符合所在地法定飲酒年齡）人士使用。註冊時須填寫生日，生日設定後不可更改（如有錯誤請聯絡我們），亦用於壽星禮遇。
  • 你須對自己發布的內容負責；不得上傳違法、侵權、不雅或騷擾性內容。
  • 內容審查：公開發布前，相片與文字會由自動系統（AI）檢查，未能確認安全者會先作人手覆核才顯示。違規者可被移除內容、限制發布或停用帳號。
  • 額度與優惠：AI 辨識設有每月額度；壽星、活動、兌換碼及邀請獎勵所得額外額度有使用期限，無現金價值，不可轉讓。我們可因濫用（例如大量註冊假帳號）取消獎勵。
  • 我們可移除被檢舉或違規的內容，並對濫用服務的帳號或裝置作出限制。
  • 請適量飲酒，飲酒不駕駛。
